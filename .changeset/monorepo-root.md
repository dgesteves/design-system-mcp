'onsystem': minor

onsystem works from a monorepo root, where Claude Code and Cursor sessions usually start. It used to find nothing there.

- **Projects.** At a workspace root (pnpm, npm, Yarn and Bun workspaces, Lerna, Nx; Turborepo through its package manager's workspaces) with no design system of its own, every workspace package goes through zero config or its own config, and each one with components is a project: the apps that use a design system and the design-system packages themselves. `inspect` lists each project with what it found, and the packages without one.
- **`check .` at the root** checks each file against its own project's design system: the nearest folder with a config, a `components.json`, a `package.json` or a `project.json`, the folder the Claude Code hook runs the check from. It reports what `check .` in each of those folders reports, file for file, skips each folder's own design-system files, and keeps one baseline at the root. `--require-design-system` there fails when no package has components and color tokens. A root config that does not set `components` applies to every project without a config of its own, with its globs relative to the root.
- **MCP tools at the root.** `list_components`, `get_component`, `search_components` and `get_tokens` take an optional `path` (the file being edited, or a project folder) and answer for that project; `check_ui` takes the project from `path`, or from `filename` for code. Without a path they list every project together, each component and token tagged with its package and the projects that use it, and a name two packages share (`Button` in `@calcom/ui` and `@coss/ui`) comes back as a list with the path that picks each.
- **Imports are followed to their declaration.** A component imported through barrels (`export { Button } from "./Button"`, `export *`) is checked against the one declared where the import leads, so with two design systems in one project, `<Button>` from `@calcom/ui` is no longer checked against `@coss/ui`'s `Button`, and Dub's `CardList.Card` (an `Object.assign` member in a barrel) is no longer reported as missing.
- `prefer-design-system-component` leaves alone elements kept from the user: `hidden`, `aria-hidden`, or out of the tab order and invisible, like the input that carries a custom select's `required`.
- The Claude Code hook also treats a folder with an Nx `project.json` as a project.
