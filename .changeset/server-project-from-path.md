The MCP server finds the project when a client starts it outside one and reports no roots, as some Agent Plugins hosts and plugin setups do (the server runs in the home or the plugin's folder). Each tool call's project is then found from the absolute path it names, `path` or, for `check_ui` with `code`, `filename`: the nearest folder at or above it with a `package.json`, `components.json` or config, or the monorepo root above that, served as if the server had been started there and kept for later calls. A call without a path answers from the project found so far, when there is one; before then, the tools return an error that says to pass the absolute path of the file being edited. Before, the server served the folder it was started in, and found no design system. A server started in a project, with `--root` or a config, or given roots by the client works as before. `check_ui` also applies the config's `overrides` to a `filename` given as an absolute path in the project.
